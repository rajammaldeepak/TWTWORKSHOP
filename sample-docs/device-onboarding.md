# Device Onboarding Guide

This document is about how a new device can be added to the fleet management system by an administrator, and it is intended to be followed carefully because mistakes made during this process can be difficult to reverse later on and may require a support ticket to be opened.

## Steps

1. The admin console should be opened.
2. Navigate to Devices.
3. A new device ID needs to be entered in the field, and then the OTP that was sent to the registered email should be entered as well.
4. Click Register.
5. The device will now show up in the list, wait for the status to change.

## Notes

- Only devices running FMS v2 or later are supported.
- If the OTP does not work, the request should be retried.
- See the API docs for more info: [Device API](./device-api.md)
- Backup docs: [old process](https://example.com/fms/legacy-onboarding)

## Troubleshooting

Contact support if issues persist.
